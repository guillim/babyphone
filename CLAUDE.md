# Rules for this repository

## Version

The version shown to users in the settings is `MARKETING_VERSION`, in `Config/App.xcconfig`.

- Every commit raises its last number by one: 0.1.1, then 0.1.2, and so on.
- Never raise the first or the middle number (0.1 to 0.2, or 0.x to 1.0) without an explicit go from the owner.
